# Kaneo Homebrew tap

Homebrew formulae for [Kaneo](https://kaneo.app), the open source project manager.

## Kaneo CLI

```bash
brew install usekaneo/tap/kaneo
```

Update with `brew upgrade kaneo`. The formula installs the prebuilt `kaneo` binary for macOS (Apple silicon and Intel) and Linux (x64 and arm64) from the [CLI releases](https://github.com/usekaneo/kaneo/releases) and checks it against the release checksums.

See the [CLI docs](https://kaneo.app/docs/cli) to sign in and get started.

The formula is updated by the `Release CLI` workflow in [usekaneo/kaneo](https://github.com/usekaneo/kaneo) whenever a new CLI version is released, so changes belong there rather than in this repository.
